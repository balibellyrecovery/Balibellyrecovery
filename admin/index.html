Pengaturan Promo

Status, nama, diskon, dan kode promo disimpan di pengaturan website. Perubahan pengaturan tidak otomatis mengubah harga/banner statis pada halaman publik; sesuaikan konten halaman dan deploy ulang jika mengubah penawaran.

Catatan: data promo Admin dan tampilan harga/banner publik masih perlu diperbarui bersama saat penawaran berubah.

Koneksi CMS

Keamanan

Halaman /admin dan alamat Worker wajib dilindungi Cloudflare Access. Jangan gunakan CMS sebelum login Access dan GitHub App selesai dikonfigurasi.
